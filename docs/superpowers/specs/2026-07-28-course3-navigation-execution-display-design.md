# 科目三导航执行信息页与视觉校准切换设计

## 目标

在遥控器发起已保存的科目三航点执行后，屏幕进入一个专用的“科目三导航执行”页面。该页面用于显示当前导航目标及相对误差；只有单边桥或台阶进入视觉校准阶段时，才自动切换到摄像头画面。

## 范围与行为

1. 执行信息页持续显示当前目标类型：普通点、单边桥或台阶。
2. 页面显示当前位置和目标位置的 `X`、`Y`、`Yaw`，以及 `dX`、`dY`、`dYaw` 和平面距离。
3. 普通点到达后不进入课程动作状态；导航立即推进到下一个目标点，页面随之更新。
4. 单边桥与台阶到达后进入 `FSM_COURSE3_TRACK_ALIGN`。此时才自动切换到视觉页，显示摄像头图像和当前状态。
5. 单边桥或台阶的校准/动作完成后，自动恢复到科目三导航执行信息页，显示下一个目标。
6. 低电压保护继续拥有显示优先级。

## 状态与数据流

Core A 维护一个与当前目标相关的课程三执行显示数据结构，并经现有 IPC 状态同步至 Core B。该数据至少包含：执行是否有效、目标航点类型、当前/目标姿态、相对误差、距离，以及课程三动作显示状态。

Core B 新增执行信息页。开始执行时切入该页面；`TRACK_ALIGN` 期间保存该页面并临时切入视觉页；视觉校准完成或动作完成后恢复执行信息页。视觉自动切屏条件只依赖 `TRACK_ALIGN`，不得由“课程三执行中”本身触发。

## 寻找中心线控制

视觉帧连续丢失达到既有丢失判定后，状态机进入寻找中心线。该分支：

- 目标前进速度固定为 `100.0`。
- 以目标地图航向为中心，连续作 `±15°` 正弦航向扫描，直到重新获得有效中心线；不设置搜索结束时间。
- 航向目标角速度上限为 `0.5 rad/s`。对振幅 `15°`（`pi/12 rad`），正弦角频率最多为 `0.5 / (pi/12)` rad/s，对应最小扫描周期约 `3.29 s`。实现中以角速度上限计算相位，避免依赖硬编码的 2 秒周期。

重新获得有效中心线时，清空搜索采样并恢复视觉校准采样流程。

## 测试

新增纯逻辑单元测试，覆盖：三种航点类型的显示文本；普通点完成时直接推进；视觉自动进入仅在 `TRACK_ALIGN`；连续正弦搜索的速度、振幅和角速度上限。现有显示状态与对准逻辑测试保持通过。

## 非目标

不改变遥控器的航点录制格式、普通导航循迹控制器，或低电压显示策略；不承诺车身实际角速度等于航向目标角速度，实际响应仍由方向控制环和车辆动力学决定。
